## Silent SPY 

Silent SPY is an Android application developed using Java and Android Studio for audio recording and managing recorded files.

## Features

- Audio recording functionality
- Background/foreground audio recording
- View and manage recorded files
- Access recorded audio files
- User-friendly Android interface
- Splash screen for application startup

## Technologies Used

- Java
- Android Studio
- Android SDK
- XML
- Android MediaRecorder
- Android Activity & Intent
- RecyclerView / Adapter
- Gradle

##  Setup & Installation

- Clone the repository:

   ```bash
   git clone https://github.com/RumiBuilds/Silent_SPY.git



- Open the project in Android Studio.
- Allow Gradle to sync and download the required dependencies.
- Connect an Android device or start an Android emulator.
- Build and run the application.
  
##   Permissions

The application may require microphone/audio recording permissions to provide its recording functionality.
Users should grant permissions only when they understand why they are required.
